# Sasirangan Banua

Katalog dan pemesanan kain sasirangan fiktif dari Banjarmasin. Situs web ini dibuat sebagai proyek **Praktikum Pemrograman Web 1**, Program Studi Teknik Informatika, Universitas Islam Kalimantan Muhammad Arsyad Al Banjari (UNISKA MAB).

> Sasirangan Banua adalah UMKM fiktif yang dipakai sebagai contoh untuk latihan.

## Halaman

- `index.html`: beranda dengan header, hero, katalog 6 produk, bagian tentang, dan jam buka galeri.
- `kontak.html`: formulir pemesanan, pertanyaan umum, dan peta lokasi.

## Struktur Folder

```
web1-2310010001/
├── index.html
├── kontak.html
├── img/                       gambar katalog (SVG)
├── bedah-kode-ai/             latihan bedah kode AI modul 1
│   ├── modul-1-perbaikan.html     kode setelah diperbaiki
│   ├── tabel-temuan.md            laporan temuan dan prompt
│   └── img/                   gambar untuk bedah kode
└── docs/
    └── jawaban-contoh.md      contoh jawaban tugas pendahuluan dan refleksi
```

## Cara Menjalankan

1. Salin (*clone*) repositori ini.
2. Buka foldernya di Visual Studio Code.
3. Klik kanan `index.html`, lalu pilih **Open with Live Server**.

## Sumber Gambar

Semua gambar adalah ilustrasi SVG buatan untuk keperluan praktikum, bukan foto produk nyata.
